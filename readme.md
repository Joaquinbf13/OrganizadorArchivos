# Organizador de Archivos en Python

Script que organiza automáticamente archivos por tipo (imágenes, documentos, vídeos, etc.)

## Funcionalidades
- Clasificación automática
- Creación de carpetas
- Soporte para múltiples formatos

## Uso
1. Modificar la ruta en el script
2. Ejecutar con Python

## Tecnologías
- Python
